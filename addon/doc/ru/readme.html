simpleCopy


Эффективное копирование, добавление и управление текстом с помощью NVDA


author: chai chaimee

url: https://github.com/chaichaimee/simpleCopy

Описание


simpleCopy — это легкое дополнение для NVDA, которое упрощает копирование текста, извлечение URL-адресов, управление историей речи и организацию истории URL-адресов.


Этот инструмент помогает быстро захватывать и организовывать информацию, не прерывая ваш рабочий процесс. Копируете ли вы текст, захватываете веб-ссылки, сохраняете произнесенный контент или управляете часто используемыми URL-адресами, simpleCopy предоставляет интуитивно понятные сочетания клавиш, которые плавно работают с NVDA.


Горячие клавиши


Все команды используют систему многократных нажатий. Нажимайте комбинацию клавиш один, два или три раза подряд для выполнения различных действий.


CTRL+Shift+A — URL, ссылка и история URL

Одинарное нажатие: Копирует URL текущей веб-страницы.

Двойное нажатие: Копирует целевой URL находящейся в фокусе гиперссылки.

Тройное нажатие: Открывает диалоговое окно «История URL» для управления сохраненными URL и гиперссылками.


CTRL+Shift+V — Копирование текста, добавление и управление буфером обмена

Одинарное нажатие: Копирует выделенный текст. Если в буфере обмена уже есть текст, новое выделение добавляется к нему.

Двойное нажатие: Копирует текст с текущей позиции курсора просмотра. Это работает с любым выделением, сделанным с помощью курсора просмотра NVDA, включая многострочное выделение и выделение всего документа.

Тройное нажатие: Очищает все содержимое буфера обмена.


F9 — Захват речи и управление ею

Одинарное нажатие: Копирует последний вывод речи от NVDA.

Двойное нажатие: Добавляет последний вывод речи к существующему содержимому буфера обмена.

Тройное нажатие: Копирует весь вывод речи, накопленный с момента первого нажатия F9.


Shift+F9 — Навигация по истории речи

Одинарное нажатие: Переход к предыдущему элементу истории речи.

Двойное нажатие: Переход к следующему элементу истории речи.

Тройное нажатие: Открывает полный файл журнала истории речи.


Функции


Вот как каждая функция работает на практике:


1. Копирование URL веб-страницы

Нажмите CTRL+Shift+A один раз при просмотре любого веб-сайта. URL текущей страницы копируется в буфер обмена. NVDA подтверждает это, произнося скопированный URL.


2. Извлечение URL гиперссылки

Установите фокус на любую ссылку и нажмите CTRL+Shift+A дважды. Целевой URL извлекается и копируется без открытия ссылки.


3. Копирование и добавление текста

Выделите текст и нажмите CTRL+Shift+V один раз. Если буфер обмена пуст, текст копируется. Если буфер обмена уже содержит текст, новое выделение добавляется с разрывом строки.


4. Копирование курсором просмотра

Используйте курсор просмотра NVDA для выбора текста (используя NVDA+Shift+Стрелка вниз или NVDA+Ctrl+Shift+Стрелка вниз для выбора нескольких строк), затем нажмите CTRL+Shift+V дважды. Весь выделенный текст с позиции курсора просмотра копируется в буфер обмена. Это работает с выделением любого размера, от одного слова до целого документа.


5. Очистка буфера обмена

Нажмите CTRL+Shift+V три раза, чтобы мгновенно очистить все содержимое буфера обмена. NVDA подтверждает это сообщением «Clean».


6. Копирование последней речи

Когда NVDA произносит что-то, что вы хотите сохранить, нажмите F9 один раз. Последняя произнесенная фраза копируется в буфер обмена.


7. Добавление речи

Нажмите F9 дважды, чтобы добавить последнюю произнесенную фразу к существующему содержимому буфера обмена.


8. Журналирование истории речи

Нажмите F9 три раза, чтобы скопировать весь речевой вывод, накопленный за текущую сессию.


9. Навигация по истории речи

Используйте Shift+F9 один раз для перемещения назад по истории речи и Shift+F9 дважды для перемещения вперед. Это позволяет просматривать прошлый речевой вывод, не меняя текущий фокус.


10. Доступ к файлу журнала речи

Нажмите Shift+F9 три раза, чтобы открыть полный файл истории речи в текстовом редакторе по умолчанию для просмотра, поиска или копирования.


11. Управление историей URL

Нажмите CTRL+Shift+A три раза, чтобы открыть диалоговое окно «История URL». В этом диалоговом окне сохраняется каждый URL и гиперссылка, скопированные с помощью CTRL+Shift+A (одиночное или двойное нажатие), чтобы вы могли обратиться к ним позже.


Использование диалогового окна «История URL»:

- Нажмите Enter на любом элементе, чтобы скопировать этот URL в буфер обмена. NVDA объявит скопированный URL.

- Нажмите клавишу «Приложения» или щелкните правой кнопкой мыши, чтобы открыть контекстное меню.

- В контекстном меню вы можете Закрепить, Редактировать, Переместить вверх, Переместить вниз или Удалить элемент.

- Нажмите клавишу Delete, чтобы быстро удалить выбранный элемент.

- Используйте команду Очистить в контекстном меню, чтобы удалить все незакрепленные элементы.


Закрепление и отображаемые имена:

- Закрепленные элементы защищены от автоматической очистки и команды очистки.

- Вы можете назначить пользовательское отображаемое имя любому URL, выбрав Редактировать. Это особенно полезно для часто используемых URL, облегчая их поиск в списке.


Лимит хранения:

- История URL ограничена 300 элементами. При достижении лимита самые старые незакрепленные элементы автоматически удаляются, чтобы освободить место для новых.


12. Интеллектуальный учет контекста

Когда вы печатаете в редактируемых полях, simpleCopy не вмешивается. Команды активируются только тогда, когда они полезны, сохраняя ваш обычный рабочий процесс.
