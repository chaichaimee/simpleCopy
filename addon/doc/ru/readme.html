Описание


simpleCopy — это легкое дополнение для NVDA, которое упрощает копирование текста, извлечение URL-адресов и управление историей речи.


Этот инструмент помогает быстро захватывать и организовывать информацию, не прерывая рабочий процесс. Копируете ли вы текст, извлекаете веб-ссылки или сохраняете речевое содержание, simpleCopy предоставляет интуитивные сочетания клавиш, которые безупречно работают с NVDA.


Горячие клавиши


Все команды используют систему многократного нажатия. Нажмите комбинацию клавиш один, два или три раза подряд для выполнения разных действий.


CTRL+Shift+A — Захват URL и ссылок

Одно нажатие: Копирует URL текущей веб-страницы.

Двойное нажатие: Копирует целевой URL выделенной гиперссылки.


CTRL+Shift+V — Копирование, добавление и управление буфером обмена

Одно нажатие: Копирует выделенный текст. Если в буфере обмена уже есть текст, новое выделение добавляется к нему.

Двойное нажатие: Копирует текст с текущей позиции курсора обзора. Работает с любым выделением, сделанным с помощью курсора обзора NVDA, включая многострочные выделения и выделение всего документа.

Тройное нажатие: Очищает все содержимое буфера обмена.


F9 — Захват и управление речью

Одно нажатие: Копирует последнюю речевую выходную информацию NVDA.

Двойное нажатие: Добавляет последнюю речевую выходную информацию к существующему содержимому буфера обмена.

Тройное нажатие: Копирует всю речевую выходную информацию, накопленную с момента первого нажатия F9.


Shift+F9 — Навигация по истории речи

Одно нажатие: Переходит к предыдущему элементу истории речи.

Двойное нажатие: Переходит к следующему элементу истории речи.

Тройное нажатие: Открывает полный файл журнала истории речи.


Возможности


Вот как работает каждая функция на практике:


1. Копирование URL веб-страницы

Нажмите CTRL+Shift+A один раз во время просмотра любого веб-сайта. URL текущей страницы копируется в буфер обмена. NVDA подтверждает это, озвучивая скопированный URL.


2. Извлечение URL гиперссылки

Сфокусируйтесь на любой ссылке и нажмите CTRL+Shift+A дважды. Целевой URL извлекается и копируется без открытия ссылки.


3. Копирование и добавление текста

Выделите текст и нажмите CTRL+Shift+V один раз. Если буфер обмена пуст, текст копируется. Если буфер обмена уже содержит текст, новое выделение добавляется с переносом строки.


4. Копирование с курсора обзора

Используйте курсор обзора NVDA для выделения текста (используя NVDA+Shift+Стрелка вниз или NVDA+CTRL+Shift+Стрелка вниз для выделения нескольких строк), затем нажмите CTRL+Shift+V дважды. Весь выделенный текст с позиции курсора обзора копируется в буфер обмена. Это работает с любым размером выделения, от одного слова до целого документа.


5. Очистка буфера обмена

Нажмите CTRL+Shift+V трижды, чтобы мгновенно очистить все содержимое буфера обмена. NVDA подтверждает это сообщением "Clean".


6. Копирование последней речи

Когда NVDA произносит что-то, что вы хотите сохранить, нажмите F9 один раз. Последняя произнесенная фраза копируется в буфер обмена.


7. Добавление речи

Нажмите F9 дважды, чтобы добавить последнюю произнесенную фразу к существующему содержимому буфера обмена.


8. Ведение журнала истории речи

Нажмите F9 трижды, чтобы скопировать всю речевую выходную информацию, накопленную за время вашей текущей сессии.


9. Навигация по истории речи

Используйте Shift+F9 один раз для перемещения назад по истории речи и Shift+F9 дважды для перемещения вперед. Это позволяет просматривать прошлые речевые выходные данные без изменения текущего фокуса.


10. Доступ к файлу журнала речи

Нажмите Shift+F9 трижды, чтобы открыть полный файл истории речи в вашем текстовом редакторе по умолчанию для просмотра, поиска или копирования.


11. Интеллектуальная контекстная осведомленность

Когда вы печатаете в редактируемых полях, simpleCopy не мешает. Команды активируются только тогда, когда они полезны, сохраняя ваш обычный рабочий процесс.
