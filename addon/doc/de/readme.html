simpleCopy


Kopieren, anhängen, einfügen und erfassen Sie alles, was Sie hören, lesen oder durchsuchen, mit wenigen einfachen Tastenkombinationen.


Autor: chai chaimee

URL: https://github.com/chaichaimee/simpleCopy


Einführung


simpleCopy verwandelt die Zwischenablage in einen schnellen, barrierefreien Arbeitsbereich. Sie können mehrere Textabschnitte in einer Zwischenablage sammeln, diese zeilenweise wieder einfügen, den gesamten Text eines Fensters kopieren, die Adresse der aktuellen Webseite oder des Links übernehmen und alles kopieren, was NVDA gerade gesprochen hat. Ein integrierter URL-Verlauf speichert die erfassten Adressen, sodass Sie sie später wiederverwenden können.


Jede Aktion wird durch Sprachausgabe oder einen kurzen Piepton angekündigt, sodass Sie immer wissen, ob der Vorgang erfolgreich war.


Tastenkombinationen


Strg+Shift+A
Einfach-Tippen: URL kopieren
Doppel-Tippen: Hyperlink kopieren
Dreifach-Tippen: URL-Verlauf
Strg+Shift+V
Einfach-Tippen: Text kopieren und anhängen
Doppel-Tippen: Zeile für Zeile einfügen
Dreifach-Tippen: Zwischenablage leeren
Shift+Windows+V
Einfach-Tippen: Fenstertext kopieren und anzeigen
F9
Einfach-Tippen: Letzte Sprachausgabe kopieren
Doppel-Tippen: Letzte Sprachausgabe anhängen
Dreifach-Tippen: Bis zur letzten Sprachausgabe kopieren
Shift+F9
Einfach-Tippen: Vorheriger Eintrag im Sprachverlauf
Doppel-Tippen: Nächster Eintrag im Sprachverlauf
Dreifach-Tippen: Datei des Sprachverlaufs öffnen

Funktionen


Text kopieren und anhängen


Markieren Sie Text und drücken Sie einmal Strg+Shift+V. Die erste Auswahl wird in die Zwischenablage kopiert. Jede weitere Auswahl wird in einer neuen Zeile an das Ende der Zwischenablage angehängt, anstatt diese zu ersetzen, und NVDA teilt Ihnen mit, wie viele Zeichen hinzugefügt wurden und wie hoch das neue Total ist. So können Sie Text von verschiedenen Orten in einer Zwischenablage zusammenfassen.


Wenn nichts markiert ist, wird die Tastenkombination als normales Strg+Shift+C an die Anwendung weitergeleitet.


Beispiel:

  1. Markieren Sie den ersten Absatz und drücken Sie Strg+Shift+V. NVDA sagt „Kopiert“.
  2. Markieren Sie einen Absatz in einem anderen Dokument und drücken Sie Strg+Shift+V. NVDA sagt „Angehängt“ zusammen mit der Anzahl der Zeichen und dem Gesamtwert.
  3. Fügen Sie mit Strg+V ein. Beide Absätze erscheinen untereinander.

Zeile für Zeile einfügen


Nimmt den Text aus der Zwischenablage und fügt ihn zeilenweise ein, sodass Sie mehrere Felder oder Formulare aus einem einzigen Textblock ausfüllen können. Leere Zeilen werden übersprungen.


  1. Kopieren oder hängen Sie den gewünschten Text an.
  2. Drücken Sie zweimal Strg+Shift+V. Sie hören einen Piepton und NVDA gibt die Anzahl der Zeilen bekannt.
  3. Gehen Sie zum ersten Zielort des Textes und drücken Sie das normale Strg+V. Die erste Zeile wird eingefügt und NVDA gibt die Zeilennummer bekannt.
  4. Gehen Sie zum nächsten Zielort und drücken Sie erneut Strg+V. Die nächste Zeile wird eingefügt.
  5. Wiederholen Sie den Vorgang, bis die letzte Zeile eingefügt ist. Ein hoher Piepton signalisiert, dass die Liste fertig ist, und Ihr ursprünglicher Zwischenablagetext wird automatisch wiederhergestellt.

Solange der zeilenweise Modus aktiv ist, können Sie weiterhin einmal Strg+Shift+V drücken, um der Warteschlange weiteren Text hinzuzufügen. Wenn Sie in der Zwischenzeit etwas anderes in die Zwischenablage kopieren, wird der Modus beendet und Strg+V fügt wie gewohnt ein.


Zwischenablage leeren


Drücken Sie dreimal Strg+Shift+V, um die Zwischenablage zu leeren. NVDA sagt „Gereinigt“. Dadurch wird auch der zeilenweise Modus beendet und sämtliche für „Bis zur letzten Sprachausgabe kopieren“ erfasste Sprache gelöscht.


Fenstertext kopieren


Drücken Sie Shift+Windows+V, um den gesamten Text des aktiven Fensters in die Zwischenablage zu kopieren. Wenn das Fenster keinen Text direkt bereitstellt, liest simpleCopy stattdessen den Text des fokussierten Steuerelements über den Prüfcursor aus. NVDA gibt die Anzahl der kopierten Zeichen und Zeilen bekannt und öffnet anschließend ein schreibgeschütztes Fenster mit dem Titel „Kopierter Text“, das genau anzeigt, was kopiert wurde. Drücken Sie Escape oder wählen Sie Schließen, um zu Ihrer Arbeit zurückzukehren.


URL kopieren


Drücken Sie in einem Webbrowser (Chrome, Firefox, Edge, Opera, Safari und Brave) einmal Strg+Shift+A, um die Adresse der aktuellen Seite zu kopieren. NVDA sagt „Kopieren“ gefolgt von der Adresse, und die Adresse wird zum URL-Verlauf hinzugefügt. Wenn keine Adresse gefunden werden kann, sagt NVDA „Keine URL“.


Wenn Sie sich in einem Eingabefeld oder in einer Anwendung befinden, die kein Browser ist, wird die Tastenkombination unverändert an die Anwendung weitergeleitet.


Hyperlink kopieren


Bewegen Sie das Navigatorobjekt auf einen Link in einer Webseite und drücken Sie zweimal Strg+Shift+A. Die Adresse dieses Links wird kopiert, angesagt und zum URL-Verlauf hinzugefügt. Wenn kein Link vorhanden ist, sagt NVDA „Kein Link gefunden“.


URL-Verlauf


Drücken Sie dreimal Strg+Shift+A, um das URL-Verlaufsfenster zu öffnen. Es listet alle mit URL kopieren oder Hyperlink kopieren erfassten Adressen auf, beginnend mit der neuesten, und merkt sich bis zu 300 Adressen zwischen Sitzungen. Eine Adresse, die Sie erneut kopieren, wandert an den Anfang der Liste.


  1. Drücken Sie dreimal Strg+Shift+A, um die Liste zu öffnen.
  2. Verwenden Sie die Pfeiltasten Oben und Unten, um eine Adresse auszuwählen.
  3. Drücken Sie Enter, um die ausgewählte Adresse in die Zwischenablage zu kopieren. Das Fenster schließt sich und NVDA gibt bekannt, was kopiert wurde.
  4. Drücken Sie Entf, um die ausgewählte Adresse zu entfernen, oder Escape, um das Fenster zu schließen.

Öffnen Sie das Kontextmenü für einen Eintrag (Anwendungstaste oder Rechtsklick), um weitere Optionen aufzurufen:


  • Löschen: Entfernt alle Einträge, die nicht angeheftet sind.
  • Anheften / Loslöschen: Schützt einen Eintrag vor dem Löschen und vor dem automatischen Bereinigen, wenn die Liste voll ist.
  • Nach oben / Nach unten: Ändert die Position des Eintrags in der Liste.
  • Bearbeiten: Weist dem Eintrag einen optionalen Anzeigenamen zu, der anstelle der Adresse angezeigt wird. Lassen Sie den Namen leer, um wieder die Adresse anzuzeigen.
  • Entfernen: Löscht den Eintrag.

Letzte Sprachausgabe kopieren


Drücken Sie einmal F9, um das letzte von NVDA gesprochene Element in die Zwischenablage zu kopieren. Ein Piepton bestätigt den Kopiervorgang. Dadurch wird auch die Aufzeichnung aller nachfolgenden Sprachausgaben von NVDA gestartet, die für „Bis zur letzten Sprachausgabe kopieren“ verwendet wird.


Letzte Sprachausgabe anhängen


Drücken Sie zweimal F9, um das letzte von NVDA gesprochene Element in einer neuen Zeile an das Ende der Zwischenablage anzuhängen, ohne das bereits Vorhandene zu ersetzen. NVDA sagt „Anhängen“.


Bis zur letzten Sprachausgabe kopieren


Sammelt eine ganze Sprachsequenz – zum Beispiel mehrere Zeilen eines Chats oder eine lange Liste, die Sie durchlesen – in einem einzigen Zwischenablage-Eintrag.


  1. Drücken Sie beim ersten gewünschten Element einmal F9. Es wird kopiert und die Aufzeichnung beginnt.
  2. Gehen Sie weiter und hören Sie sich die anderen gewünschten Elemente an. Alles, was NVDA spricht, wird aufgezeichnet.
  3. Drücken Sie dreimal F9. NVDA sagt „Bis zur letzten kopieren“, und alles, was seit der ersten Kopie aufgezeichnet wurde, wird zeilenweise in die Zwischenablage übernommen.

Wenn nichts aufgezeichnet wurde, hören Sie einen Fehlerpiepton. Die von simpleCopy selbst gesprochenen Meldungen werden nicht aufgezeichnet.


Navigation im Sprachverlauf


simpleCopy speichert die letzten 500 von NVDA gesprochenen Elemente. Drücken Sie einmal Shift+F9, um das vorherige Element zu hören, wobei Sie bei jedem Mal weiter zurückgehen. Drücken Sie zweimal Shift+F9, um sich wieder zum neuesten Element vorzuarbeiten. Wenn es in dieser Richtung nichts Weiteres gibt, hören Sie einen Fehlerpiepton.


Datei des Sprachverlaufs öffnen


Drücken Sie dreimal Shift+F9, um den Sprachverlauf in einer Textdatei zu speichern und in Ihrem Standard-Texteditor zu öffnen. Doppelte Zeilen werden nur einmal aufgeführt, beginnend mit der neuesten. Die Datei ist nützlich, um alles zu überprüfen oder zu durchsuchen, was während Ihrer Sitzung gesprochen wurde.
