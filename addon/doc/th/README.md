## Опис

**simpleCopy** — це легкий додаток для NVDA, який спрощує копіювання тексту, вилучення URL-адрес та керування історією мовлення.

Цей інструмент допомагає швидко захоплювати та організовувати інформацію, не перериваючи робочий процес. Копіюєте ви текст, вилучаєте веб-посилання чи зберігаєте мовленнєвий вміст, simpleCopy надає інтуїтивні клавішні скорочення, які бездоганно працюють з NVDA.

## Гарячі клавіші

Усі команди використовують систему багаторазового натискання. Натисніть комбінацію клавіш один, два або три рази поспіль для виконання різних дій.

### CTRL+Shift+A — Захоплення URL та посилань

- **Одне натискання:** Копіює URL поточної веб-сторінки.
- **Подвійне натискання:** Копіює цільовий URL виділеного гіперпосилання.

### CTRL+Shift+V — Копіювання, додавання та керування буфером обміну

- **Одне натискання:** Копіює виділений текст. Якщо в буфері обміну вже є текст, нове виділення додається до нього.
- **Подвійне натискання:** Копіює текст з поточної позиції курсора огляду. Працює з будь-яким виділенням, зробленим за допомогою курсора огляду NVDA, включаючи багаторядкові виділення та виділення всього документа.
- **Потрійне натискання:** Очищує весь вміст буфера обміну.

### F9 — Захоплення та керування мовленням

- **Одне натискання:** Копіює останнє мовленнєве вихідне повідомлення NVDA.
- **Подвійне натискання:** Додає останнє мовленнєве вихідне повідомлення до наявного вмісту буфера обміну.
- **Потрійне натискання:** Копіює все мовленнєве вихідне повідомлення, накопичене з моменту першого натискання F9.

### Shift+F9 — Навігація по історії мовлення

- **Одне натискання:** Переходить до попереднього елемента історії мовлення.
- **Подвійне натискання:** Переходить до наступного елемента історії мовлення.
- **Потрійне натискання:** Відкриває повний файл журналу історії мовлення.

## Можливості

Ось як працює кожна функція на практиці:

### 1. Копіювання URL веб-сторінки

Натисніть **CTRL+Shift+A один раз** під час перегляду будь-якого веб-сайту. URL поточної сторінки копіюється в буфер обміну. NVDA підтверджує це, озвучуючи скопійований URL.

### 2. Вилучення URL гіперпосилання

Сфокусуйтесь на будь-якому посиланні та натисніть **CTRL+Shift+A двічі**. Цільовий URL вилучається та копіюється без відкриття посилання.

### 3. Копіювання та додавання тексту

Виділіть текст і натисніть **CTRL+Shift+V один раз**. Якщо буфер обміну порожній, текст копіюється. Якщо буфер обміну вже містить текст, нове виділення додається з розривом рядка.

### 4. Копіювання з курсора огляду

Використовуйте курсор огляду NVDA для виділення тексту (використовуючи NVDA+Shift+Стрілка вниз або NVDA+CTRL+Shift+Стрілка вниз для виділення кількох рядків), потім натисніть **CTRL+Shift+V двічі**. Весь виділений текст з позиції курсора огляду копіюється в буфер обміну. Це працює з будь-яким розміром виділення, від одного слова до цілого документа.

### 5. Очищення буфера обміну

Натисніть **CTRL+Shift+V тричі**, щоб миттєво очистити весь вміст буфера обміну. NVDA підтверджує це повідомленням "Clean".

### 6. Копіювання останнього мовлення

Коли NVDA промовляє щось, що ви хочете зберегти, натисніть **F9 один раз**. Остання промовлена фраза копіюється в буфер обміну.

### 7. Додавання мовлення

Натисніть **F9 двічі**, щоб додати останню промовлену фразу до наявного вмісту буфера обміну.

### 8. Ведення журналу історії мовлення

Натисніть **F9 тричі**, щоб скопіювати все мовленнєве вихідне повідомлення, накопичене під час вашої поточної сесії.

### 9. Навігація по історії мовлення

Використовуйте **Shift+F9 один раз** для переміщення назад по історії мовлення та **Shift+F9 двічі** для переміщення вперед. Це дозволяє переглядати минулі мовленнєві вихідні дані без зміни поточного фокусу.

### 10. Доступ до файлу журналу мовлення

Натисніть **Shift+F9 тричі**, щоб відкрити повний файл історії мовлення у вашому текстовому редакторі за замовчуванням для перегляду, пошуку або копіювання.

### 11. Інтелектуальна контекстна обізнаність

Коли ви друкуєте в редагованих полях, simpleCopy не заважає. Команди активуються лише тоді, коли вони корисні, зберігаючи ваш звичайний робочий процес.
