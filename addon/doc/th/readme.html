simpleCopy


คัดลอก ต่อข้อความ และจัดการข้อมูลได้อย่างมีประสิทธิภาพด้วย NVDA


author: chai chaimee

url: https://github.com/chaichaimee/simpleCopy

รายละเอียด


simpleCopy เป็นแอดออน NVDA ขนาดเบาที่ช่วยลดความซับซ้อนในการคัดลอกข้อความ แยก URL จัดการประวัติเสียงพูด และจัดการประวัติ URL


เครื่องมือนี้ช่วยให้คุณบันทึกและจัดการข้อมูลได้อย่างรวดเร็วโดยไม่ขัดจังหวะการทำงานของคุณ ไม่ว่าคุณจะกำลังคัดลอกข้อความ บันทึกลิงก์เว็บ บันทึกเนื้อหาที่อ่าน หรือจัดการ URL ที่ใช้บ่อย simpleCopy มีแป้นพิมพ์ลัดที่ใช้งานง่ายและทำงานร่วมกับ NVDA ได้อย่างราบรื่น


แป้นพิมพ์ลัด


คำสั่งทั้งหมดใช้ระบบกดหลายครั้ง กดชุดคีย์ผสมหนึ่งครั้ง สองครั้ง หรือสามครั้งติดต่อกันอย่างรวดเร็วเพื่อดำเนินการต่างๆ


CTRL+Shift+A — URL, ลิงก์ และประวัติ URL

กดหนึ่งครั้ง: คัดลอก URL ของหน้าเว็บปัจจุบัน

กดสองครั้ง: คัดลอก URL ปลายทางของไฮเปอร์ลิงก์ที่โฟกัสอยู่

กดสามครั้ง: เปิดกล่องโต้ตอบประวัติ URL เพื่อจัดการ URL และไฮเปอร์ลิงก์ที่บันทึกไว้


CTRL+Shift+V — คัดลอกข้อความ ต่อข้อความ และจัดการคลิปบอร์ด

กดหนึ่งครั้ง: คัดลอกข้อความที่เลือก หากมีข้อความอยู่ในคลิปบอร์ดอยู่แล้ว ข้อความที่เลือกใหม่จะถูกต่อท้ายข้อความเดิม

กดสองครั้ง: คัดลอกข้อความจากตำแหน่งเคอร์เซอร์ทบทวนปัจจุบัน ใช้ได้กับการเลือกข้อความใดๆ ที่ทำด้วยเคอร์เซอร์ทบทวนของ NVDA รวมถึงการเลือกหลายบรรทัดและการเลือกเอกสารทั้งหมด

กดสามครั้ง: ล้างเนื้อหาทั้งหมดออกจากคลิปบอร์ด


F9 — บันทึกและจัดการเสียงพูด

กดหนึ่งครั้ง: คัดลอกเสียงพูดล่าสุดจาก NVDA

กดสองครั้ง: ต่อเสียงพูดล่าสุดเข้ากับเนื้อหาในคลิปบอร์ดที่มีอยู่

กดสามครั้ง: คัดลอกเสียงพูดทั้งหมดที่สะสมมาตั้งแต่การกด F9 ครั้งแรก


Shift+F9 — นำทางประวัติเสียงพูด

กดหนึ่งครั้ง: ไปยังรายการประวัติเสียงพูดก่อนหน้า

กดสองครั้ง: ไปยังรายการประวัติเสียงพูดถัดไป

กดสามครั้ง: เปิดไฟล์บันทึกประวัติเสียงพูดฉบับเต็ม


ฟีเจอร์หลัก


วิธีการทำงานของแต่ละฟีเจอร์ในทางปฏิบัติ:


1. คัดลอก URL หน้าเว็บ

กด CTRL+Shift+A หนึ่งครั้ง ขณะเรียกดูเว็บไซต์ใดๆ URL ของหน้าปัจจุบันจะถูกคัดลอกไปยังคลิปบอร์ดของคุณ NVDA จะยืนยันด้วยการพูด URL ที่คัดลอก


2. แยก URL ไฮเปอร์ลิงก์

ไปที่ลิงก์ใดก็ได้แล้วกด CTRL+Shift+A สองครั้ง URL ปลายทางจะถูกแยกและคัดลอกโดยไม่ต้องเปิดลิงก์


3. คัดลอกและต่อข้อความ

เลือกข้อความแล้วกด CTRL+Shift+V หนึ่งครั้ง หากคลิปบอร์ดว่างเปล่า ข้อความจะถูกคัดลอก หากคลิปบอร์ดมีข้อความอยู่แล้ว ข้อความที่เลือกใหม่จะถูกต่อท้ายโดยขึ้นบรรทัดใหม่


4. คัดลอกด้วยเคอร์เซอร์ทบทวน

ใช้เคอร์เซอร์ทบทวนของ NVDA เพื่อเลือกข้อความ (โดยใช้ NVDA+Shift+ลูกศรลง หรือ NVDA+Ctrl+Shift+ลูกศรลง เพื่อเลือกหลายบรรทัด) จากนั้นกด CTRL+Shift+V สองครั้ง ข้อความที่เลือกทั้งหมดจากตำแหน่งเคอร์เซอร์ทบทวนจะถูกคัดลอกไปยังคลิปบอร์ด ใช้งานได้กับการเลือกทุกขนาด ตั้งแต่คำเดียวไปจนถึงเอกสารทั้งชุด


5. ล้างคลิปบอร์ด

กด CTRL+Shift+V สามครั้ง เพื่อล้างเนื้อหาคลิปบอร์ดทั้งหมดทันที NVDA จะยืนยันด้วยข้อความ "Clean"


6. คัดลอกเสียงพูดล่าสุด

เมื่อ NVDA พูดข้อความที่คุณต้องการบันทึก ให้กด F9 หนึ่งครั้ง วลีที่พูดล่าสุดจะถูกคัดลอกไปยังคลิปบอร์ดของคุณ


7. ต่อเสียงพูด

กด F9 สองครั้ง เพื่อต่อวลีที่พูดล่าสุดเข้ากับเนื้อหาในคลิปบอร์ดที่มีอยู่


8. บันทึกประวัติเสียงพูด

กด F9 สามครั้ง เพื่อคัดลอกเสียงพูดทั้งหมดที่สะสมในช่วงเซสชันปัจจุบันของคุณ


9. นำทางประวัติเสียงพูด

ใช้ Shift+F9 หนึ่งครั้ง เพื่อย้อนกลับไปในประวัติเสียงพูด และ Shift+F9 สองครั้ง เพื่อไปข้างหน้า ช่วยให้คุณทบทวนเสียงพูดที่ผ่านมาได้โดยไม่ต้องเปลี่ยนโฟกัสปัจจุบัน


10. เข้าถึงไฟล์บันทึกเสียงพูด

กด Shift+F9 สามครั้ง เพื่อเปิดไฟล์ประวัติเสียงพูดฉบับเต็มในโปรแกรมแก้ไขข้อความเริ่มต้นของคุณเพื่อตรวจสอบ ค้นหา หรือคัดลอก


11. จัดการประวัติ URL

กด CTRL+Shift+A สามครั้ง เพื่อเปิดกล่องโต้ตอบประวัติ URL กล่องโต้ตอบนี้จะจัดเก็บทุก URL และไฮเปอร์ลิงก์ที่คุณคัดลอกโดยใช้ CTRL+Shift+A (กดหนึ่งครั้งหรือสองครั้ง) เพื่อให้คุณสามารถเข้าถึงได้อีกครั้งในภายหลัง


การใช้กล่องโต้ตอบประวัติ URL:

- กด Enter บนรายการใดก็ได้เพื่อคัดลอก URL นั้นไปยังคลิปบอร์ด NVDA จะประกาศ URL ที่คัดลอก

- กด คีย์แอปพลิเคชัน หรือคลิกขวาเพื่อเปิดเมนูบริบท

- จากเมนูบริบท คุณสามารถ ปักหมุด, แก้ไข, ย้ายขึ้น, ย้ายลง หรือ ลบ รายการได้

- กดปุ่ม Delete เพื่อลบรายการที่เลือกอย่างรวดเร็ว

- ใช้คำสั่ง ล้าง จากเมนูบริบทเพื่อลบรายการทั้งหมดที่ไม่ได้ปักหมุด


การปักหมุดและชื่อที่แสดง:

- รายการที่ปักหมุดจะได้รับการปกป้องจากการล้างข้อมูลอัตโนมัติและคำสั่งล้าง

- คุณสามารถกำหนดชื่อที่แสดงแบบกำหนดเองให้กับ URL ใดก็ได้โดยเลือก แก้ไข ซึ่งจะมีประโยชน์มากสำหรับ URL ที่คุณใช้บ่อย ช่วยให้ระบุตัวตนในรายการได้ง่ายขึ้น


ขีดจำกัดการจัดเก็บ:

- ประวัติ URL ถูกจำกัดไว้ที่ 300 รายการ เมื่อถึงขีดจำกัด รายการที่ไม่ได้ปักหมุดที่เก่าที่สุดจะถูกลบออกโดยอัตโนมัติเพื่อให้มีที่ว่างสำหรับรายการใหม่


12. ระบบรับรู้บริบทอัจฉริยะ

เมื่อคุณพิมพ์ในช่องที่แก้ไขได้ simpleCopy จะไม่รบกวนการทำงาน คำสั่งจะทำงานเฉพาะเมื่อมีประโยชน์เท่านั้น โดยรักษาเวิร์กโฟลว์ตามปกติของคุณไว้



สนับสนุนฉัน

หากแอดออนนี้ช่วยให้คุณทำงานได้อย่างมีประสิทธิภาพมากขึ้น โปรดพิจารณาสับสนุนการพัฒนาในอนาคตด้วยการบริจาคเล็กน้อย
