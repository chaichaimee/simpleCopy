SimpleCopy


คัดลอกทุกอย่าง ทุกที่ เพียงแค่กดปุ่ม — ข้อความ, หน้าต่าง, URL และแม้แต่สิ่งที่ NVDA เพิ่งพูดไป


ผู้พัฒนา: chai chaimee

url: https://github.com/chaichaimee/simpleCopy


บทนำ


SimpleCopy คือส่วนเสริมของ NVDA ที่ช่วยให้การคัดลอกข้อมูลเป็นเรื่องง่ายดาย ไม่ว่าคุณจะกำลังทำอะไรอยู่บนคอมพิวเตอร์ก็ตาม


แทนที่จะต้องคอยจำและกดปุ่มคัดลอกหลายๆ ชุดตามแต่ละสถานการณ์ SimpleCopy มีปุ่มลัดที่จำง่ายเพียง 4 ชุด ซึ่งแต่ละชุดสามารถทำงานที่เกี่ยวข้องกันได้หลายอย่าง ขึ้นอยู่กับจำนวนครั้งที่คุณกดปุ่ม คุณสามารถใช้ SimpleCopy เพื่อ:


• คัดลอกหรือต่อเติมข้อความที่เลือกไว้ และยังสามารถดึงเนื้อหาทั้งหมดของหน้าต่างมาได้แม้ไม่ได้เลือกข้อความใดๆ ไว้เลย
• คัดลอกที่อยู่ของเว็บเพจที่คุณกำลังเปิดอยู่ หรือคัดลอกลิงก์ปลายทาง พร้อมทั้งเก็บประวัติ URL ที่คุณเคยคัดลอกไว้ให้ค้นหาได้สะดวก
• คัดลอกคำพูดล่าสุดที่ NVDA เพิ่งพูดออกมาได้ทันที — และยังสามารถบันทึกข้อความเสียงพูดต่อเนื่องไปเรื่อยๆ จนกว่าคุณจะสั่งหยุด
• ย้อนกลับไปฟังหรือเลื่อนไปข้างหน้าตามประวัติเสียงที่ NVDA เคยพูดไว้ก่อนหน้า และเปิดไฟล์บันทึกประวัติเสียงพูดได้ทุกเมื่อ


ทุกการทำงานจะมีเสียงพูดแจ้งเตือนและสัญญาณเสียงยืนยันอย่างชัดเจน ทำให้คุณทราบสถานะการคัดลอกได้ทันที


ปุ่มลัด (Hot Keys)


Control+Shift+V
กด 1 ครั้ง : คัดลอกหรือนำข้อความที่เลือกไปต่อเติมในคลิปบอร์ด
กด 2 ครั้ง : คัดลอกข้อความทั้งหมดจากหน้าต่างปัจจุบัน และแสดงผลในหน้าต่างทบทวนข้อความ
กด 3 ครั้ง : ล้างข้อมูลในคลิปบอร์ด

Control+Shift+A
กด 1 ครั้ง : คัดลอก URL ของหน้าเว็บเพจปัจจุบัน
กด 2 ครั้ง : คัดลอก URL ของลิงก์ที่อยู่ใต้ Navigator Object
กด 3 ครั้ง : เปิดหน้าต่างประวัติ URL

F9
กด 1 ครั้ง : คัดลอกคำพูดล่าสุดของ NVDA และเริ่มเก็บบันทึกเสียงพูดต่อจากนั้น
กด 2 ครั้ง : นำคำพูดล่าสุดไปต่อเติมในคลิปบอร์ดแบบเงียบๆ
กด 3 ครั้ง : คัดลอกข้อความเสียงพูดทั้งหมดที่เก็บบันทึกไว้ตั้งแต่เริ่มกดครั้งแรก

Shift+F9
กด 1 ครั้ง : ย้อนกลับไปอ่านข้อความเสียงพูดก่อนหน้าในประวัติ
กด 2 ครั้ง : เลื่อนไปข้างหน้าในประวัติเสียงพูด
กด 3 ครั้ง : เปิดไฟล์บันทึกประวัติการพูดทั้งหมด

คุณสมบัติการทำงาน


1. ระบบคัดลอกและต่อเติมข้อความอัจฉริยะ (Control+Shift+V)


ปุ่มลัดนี้จะปรับการทำงานตามข้อความที่คุณเลือก และจำนวนครั้งที่คุณกดปุ่มภายในเวลาครึ่งวินาที


กด 1 ครั้ง — คัดลอกหรือต่อเติมข้อความที่เลือก

ขั้นตอนการทำงาน:
1. SimpleCopy จะตรวจสอบวัตถุ (Object) ที่กำลังโฟกัสอยู่ และพยายามอ่านข้อความที่ถูกเลือกไว้
2. สำหรับ NVDA/Python เวอร์ชันใหม่ ระบบจะตรวจเช็กการเลือกข้อความใน Browse-mode document ก่อน หากไม่พบจึงจะไปอ่านจาก Text object โดยตรง ส่วนในเวอร์ชันเก่าจะอ่านจาก Text object โดยตรงก่อน
3. หากทั้งสองวิธีไม่พบข้อความที่เลือกไว้ ระบบจะส่งคำสั่งคัดลอกมาตรฐาน Control+Shift+C ที่ใช้งานในโปรแกรมต่างๆ ให้โดยอัตโนมัติ เพื่อไม่ให้คุณเสียฟังก์ชันการทำงานเดิม
4. เมื่อพบข้อความ ระบบจะไม่เขียนทับข้อมูลเดิมในคลิปบอร์ดทันที แต่จะนำข้อความใหม่ไปต่อท้ายข้อมูลที่มีอยู่เดิมโดยขึ้นบรรทัดใหม่ให้ หากคลิปบอร์ดว่างเปล่าก็จะคัดลอกข้อความเป็นปกติ
5. NVDA จะขานบอกว่าเป็นการ "Appended" (ต่อเติม) หรือ "Copied" (คัดลอก) พร้อมทั้งบอกจำนวนตัวอักษรที่เพิ่มเข้ามา และบอกจำนวนตัวอักษรรวมทั้งหมดเมื่อมีการต่อเติมข้อความ

กด 2 ครั้ง — คัดลอกเนื้อหาทั้งหน้าต่างและเปิดอ่านทบทวน

ขั้นตอนการทำงาน:
1. SimpleCopy จะพยายามอ่านเนื้อหาทั้งหมดของหน้าต่างปัจจุบันออกมาเป็นข้อความชุดเดียว โดยอ้างอิงตำแหน่ง Review Cursor เดียวกับคำสั่ง Review ของ NVDA
2. หากอ่านได้ข้อความน้อยมาก (น้อยกว่า 100 ตัวอักษร) ระบบจะใช้วิธีไล่สแกนวัตถุทีละตัวในหน้าต่างนั้น เพื่อดึงชื่อ (Name), ค่า (Value), คำอธิบาย (Description) และข้อความที่แก้ไขได้ จากวัตถุสูงสุด 200 ชิ้น ทำให้ไม่พลาดข้อมูลสำคัญ
3. ข้อความที่รวบรวมได้จะถูกคัดลอกไปยังคลิปบอร์ด และ NVDA จะแจ้งจำนวนตัวอักษรและจำนวนบรรทัดรวมทั้งหมดพร้อมเสียงสัญญาณยืนยัน
4. เมื่อเสียงแจ้งเตือนพูดจบลงแล้ว (SimpleCopy รอให้สังเคราะห์เสียงพูดจบจริงๆ ไม่ใช่การตั้งเวลารอแบบสุ่ม) หน้าต่าง "Copied Text" จะเด้งขึ้นมาแสดงข้อความทั้งหมดในกล่อง Read-only ที่สามารถเลื่อนอ่าน ค้นหา หรือเลือกข้อความได้ตามต้องการ และกด Escape เพื่อปิดหน้าต่างได้

กด 3 ครั้ง — ล้างคลิปบอร์ด

ล้างข้อมูลใน Windows clipboard ทั้งหมด รีเซ็ตสถานะการคัดลอกข้อความภายในของ SimpleCopy และล้างข้อมูลเสียงพูดที่บันทึกค้างไว้ NVDA จะขานบอกว่า "Clean" เพื่อยืนยัน

2. การคัดลอก URL และไฮเปอร์ลิงก์พร้อมระบบประวัติ (Control+Shift+A)


กด 1 ครั้ง — คัดลอก URL ของหน้าเว็บปัจจุบัน

ขั้นตอนการทำงาน:
1. หากคุณกำลังโฟกัสอยู่ในช่องกรอกข้อความ (Editable text field) SimpleCopy จะส่งผ่านปุ่มกด Control+Shift+A ให้ทำงานตามปกติของโปรแกรมนั้นๆ เพื่อไม่ให้รบกวนปุ่มลัดเดิมของแอปพลิเคชัน
2. หากไม่อยู่ในช่องกรอกข้อความ และโปรแกรมที่ใช้อยู่เป็นเว็บเบราว์เซอร์ที่รองรับ (Chrome, Firefox, Edge, Opera, Safari หรือ Brave) SimpleCopy จะค้นหา URL โดยเรียงลำดับจาก: Accessible document's value, Browse-mode document URL, UI Automation Url และวิธีเฉพาะของ Browser App-module ตามลำดับ
3. ที่อยู่ URL จะถูกคัดลอกลงคลิปบอร์ด พร้อมอ่านออกเสียงให้ฟัง และบันทึกลงในรายการประวัติ URL ให้โดยอัตโนมัติ
4. หากไม่อยู่ในเบราว์เซอร์ที่รองรับ ปุ่มกดจะถูกส่งผ่านเป็น Control+Shift+A มาตรฐาน

กด 2 ครั้ง — คัดลอก URL ของไฮเปอร์ลิงก์

ขณะท่องเว็บ คำสั่งนี้จะตรวจสอบวัตถุที่อยู่ใต้ Navigator cursor ของ NVDA (หรือวัตถุแม่ที่ใกล้เคียง) เพื่อหาลิงก์ และดึง URL ปลายทางตามช่องทางที่เบราว์เซอร์เปิดไว้ จากนั้นคัดลอกลงคลิปบอร์ด อ่านออกเสียง และบันทึกลงในประวัติ URL

กด 3 ครั้ง — เปิดประวัติ URL

เปิดหน้าต่างประวัติ URL ซึ่งจะแสดงรายการ URL ทั้งหมดที่คุณเคยคัดลอกไว้ โดยเรียงจากรายการล่าสุดก่อน (เก็บได้สูงสุด 300 รายการ โดยรายการที่ปักหมุดไว้จะไม่ถูกลบอัตโนมัติ) ในหน้าต่างนี้คุณสามารถ:
• กด Enter เพื่อคัดลอก URL นั้นซ้ำอีกครั้ง
• คลิกขวา หรือกดปุ่ม Context Menu เพื่อปักหมุด/ถอดหมุด, เลื่อนขึ้น, เลื่อนลง, แก้ไขชื่อที่แสดง (Edit), ลบรายการ หรือลบรายการทั้งหมดที่ไม่ใช่รายการปักหมุด
• ประวัติจะถูกบันทึกลงไฟล์ในโฟลเดอร์การตั้งค่าของ NVDA โดยอัตโนมัติ ทำให้ข้อมูลไม่สูญหายเมื่อรีสตาร์ทเครื่อง

3. การเก็บบันทึกและเล่นเสียงพูดซ้ำ (F9)


SimpleCopy จะเก็บบันทึกประวัติคำพูด 500 รายการล่าสุดของ NVDA ไว้เบื้องหลังอย่างเงียบๆ เพื่อให้คุณคัดลอกหรือย้อนฟังได้ทุกเมื่อที่ต้องการ


กด 1 ครั้ง — คัดลอกคำพูดล่าสุดและเริ่มเก็บบันทึกเสียงพูด

ขั้นตอนการทำงาน:
1. คัดลอกประโยคล่าสุดที่ NVDA เพิ่งพูดออกไปลงคลิปบอร์ดทันที พร้อมเสียงสัญญาณยืนยัน
2. เข้าสู่โหมด "บันทึกเสียง": ตั้งแต่จุดนี้เป็นต้นไป ทุกประโยคที่ NVDA พูดจะถูกนำไปเก็บไว้ในบัฟเฟอร์ภายในอย่างเงียบๆ เพื่อรอคัดลอกพร้อมกันทั้งหมดในการกด 3 ครั้ง ส่วนการประกาศสถานะซ้ำๆ (เช่น การอ่านสถานะของ Checkbox ซ้ำ) ระบบจะรวมประโยคให้อัตโนมัติไม่ให้เกิดข้อมูลซ้ำซ้อน

กด 2 ครั้ง — นำคำพูดล่าสุดไปต่อเติมแบบเงียบๆ

นำประโยคล่าสุดไปต่อท้ายข้อมูลเดิมที่มีอยู่ในคลิปบอร์ด (ขึ้นบรรทัดใหม่) โดยไม่กระทบเนื้อหาเดิม และยืนยันด้วยเสียงพูด "Append"

กด 3 ครั้ง — คัดลอกข้อความที่บันทึกไว้ทั้งหมด

หากเปิดโหมดบันทึกไว้ ระบบจะรวบรวมคำพูดทั้งหมดที่เก็บบันทึกไว้ตั้งแต่กดครั้งแรกนำมารวมเป็นข้อความชุดเดียว (แยกบรรทัดกัน) คัดลอกลงคลิปบอร์ด อ่านแจ้งเตือนว่า "Copy Until Last" และหยุดการบันทึก

4. การท่องดูประวัติเสียงพูด (Shift+F9)


กด 1 ครั้ง — ย้อนกลับไปประวัติก่อนหน้า

เลื่อนย้อนกลับไป 1 ลำดับในประวัติเสียงพูดของ NVDA และอ่านประโยคนั้นให้ฟังอีกครั้ง ช่วยให้ฟังข้อความที่ฟังไม่ทันได้สะดวก

กด 2 ครั้ง — เลื่อนไปข้างหน้า

เลื่อนกลับมาข้างหน้า 1 ลำดับเข้าหาเสียงพูดล่าสุด และอ่านประโยคนั้นให้ฟัง

กด 3 ครั้ง — เปิดไฟล์บันทึกประวัติเสียงพูด

ส่งออกประวัติเสียงพูดทั้งหมดที่ไม่ซ้ำกันออกมาเป็นไฟล์ข้อความ (.txt) ในโฟลเดอร์ตั้งค่าของ NVDA และเปิดขึ้นมาด้วยโปรแกรมแก้ไขข้อความหลักของคุณ เพื่ออ่าน ค้นหา หรือบันทึกเก็บไว้

หมายเหตุ: ปุ่มลัดที่ใช้การนับจำนวนครั้งการกดทั้งหมด มีระยะเวลารอกดซ้ำภายใน 0.5 วินาที เพื่อแยกแยะการกด 1 ครั้ง, 2 ครั้ง หรือ 3 ครั้ง ดังนั้นกรุณากดปุ่มต่อเนื่องกันด้วยความเร็วที่เหมาะสม
