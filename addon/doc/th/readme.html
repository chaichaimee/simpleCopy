simpleCopy


คัดลอก ต่อข้อความ วาง และบันทึกทุกสิ่งที่คุณได้ยิน อ่าน หรือเรียกดู ด้วยการกดแป้นพิมพ์เพียงไม่กี่ครั้ง


ผู้พัฒนา: chai chaimee

เว็บไซต์: https://github.com/chaichaimee/simpleCopy


บทนำ


simpleCopy เปลี่ยนคลิปบอร์ดให้เป็นพื้นที่ทำงานที่รวดเร็วและเข้าถึงได้ง่าย ช่วยให้คุณรวบรวมข้อความหลาย ๆ ส่วนไว้ในคลิปบอร์ดเดียว นำกลับมาวางทีละบรรทัด คัดลอกข้อความทั้งหมดของหน้าต่าง ดึง URL ของหน้าเว็บหรือลิงก์ที่คุณกำลังใช้งานอยู่ และคัดลอกทุกสิ่งที่ NVDA เพิ่งพูดออกไป ระบบประวัติ URL ในตัวจะเก็บรักษา URL ที่คุณเคยบันทึกไว้เพื่อให้คุณสามารถนำกลับมาใช้ใหม่ได้ในภายหลัง


ทุกการกระทำจะมีเสียงพูดหรือเสียงบี๊บสั้น ๆ แจ้งเตือน เพื่อให้คุณทราบเสมอว่าการดำเนินการนั้นสำเร็จหรือไม่


แป้นพิมพ์ลัด


Ctrl+Shift+A
กด 1 ครั้ง: คัดลอก URL
กด 2 ครั้ง: คัดลอกไฮเปอร์ลิงก์
กด 3 ครั้ง: ประวัติ URL
Ctrl+Shift+V
กด 1 ครั้ง: คัดลอกและต่อท้ายข้อความ
กด 2 ครั้ง: วางทีละบรรทัด
กด 3 ครั้ง:ล้างคลิปบอร์ด
Shift+Windows+V
กด 1 ครั้ง: คัดลอกข้อความในหน้าต่างและแสดงขึ้นมา
F9
กด 1 ครั้ง: คัดลอกคำพูดล่าสุด
กด 2 ครั้ง: ต่อท้ายคำพูดล่าสุด
กด 3 ครั้ง: คัดลอกจนถึงคำพูดล่าสุด
Shift+F9
กด 1 ครั้ง: รายการประวัติคำพูดก่อนหน้า
กด 2 ครั้ง: รายการประวัติคำพูดถัดไป
กด 3 ครั้ง: เปิดไฟล์ประวัติคำพูด

คุณสมบัติ


คัดลอกและต่อท้ายข้อความ


เลือกข้อความบางส่วนแล้วกด Ctrl+Shift+V 1 ครั้ง ข้อความที่เลือกครั้งแรกจะถูกคัดลอกไปยังคลิปบอร์ด การเลือกข้อความครั้งต่อ ๆ ไปจะถูกนำไปต่อท้ายที่บรรทัดใหม่ในคลิปบอร์ดแทนที่จะเป็นการแทนที่ข้อความเดิม และ NVDA จะบอกจำนวนตัวอักษรที่เพิ่มเข้ามาพร้อมกับยอดรวมใหม่ ช่วยให้คุณรวบรวมข้อความจากหลาย ๆ แหล่งมาไว้ในคลิปบอร์ดเดียวได้


หากไม่มีการเลือกข้อความใด ๆ ชุดคำสั่งนี้จะถูกส่งต่อไปยังแอปพลิเคชันเสมือนกด Ctrl+Shift+C ตามปกติ


ตัวอย่าง:

  1. เลือกย่อหน้าที่หนึ่งแล้วกด Ctrl+Shift+V NVDA จะพูดว่า "คัดลอกแล้ว"
  2. เลือกย่อหน้าในเอกสารอื่นแล้วกด Ctrl+Shift+V NVDA จะพูดว่า "ต่อท้ายแล้ว" พร้อมบอกจำนวนตัวอักษรและยอดรวม
  3. วางด้วย Ctrl+V จะปรากฏทั้งสองย่อหน้าเรียงต่อกันลงมา

วางทีละบรรทัด


นำข้อความในคลิปบอร์ดมาวางทีละบรรทัด เพื่อให้คุณสามารถกรอกข้อมูลหลายช่องหรือหลายฟอร์มได้จากชุดข้อความบล็อกเดียว โดยจะข้ามบรรทัดว่างให้อัตโนมัติ


  1. คัดลอกหรือต่อท้ายข้อความที่คุณต้องการใช้งาน
  2. กด Ctrl+Shift+V สองครั้ง คุณจะได้ยินเสียงบี๊บและ NVDA จะประกาศจำนวนบรรทัด
  3. ย้ายไปยังตำแหน่งแรกที่คุณต้องการวางข้อความแล้วกด Ctrl+V ตามปกติ บรรทัดแรกจะถูกวางลงไปและ NVDA จะประกาศหมายเลขบรรทัด
  4. ย้ายไปยังตำแหน่งถัดไปแล้วกด Ctrl+V อีกครั้ง เพื่อวางบรรทัดถัดไป
  5. ทำซ้ำจนกว่าจะวางครบถึงบรรทัดสุดท้าย จะมีเสียงบี๊บเสียงสูงแจ้งว่าสิ้นสุดรายการแล้ว และข้อความเดิมในคลิปบอร์ดของคุณจะถูกกู้คืนโดยอัตโนมัติ

ในขณะที่โหมดวางทีละบรรทัดกำลังทำงาน คุณยังคงสามารถกด Ctrl+Shift+V หนึ่งครั้งเพื่อต่อท้ายข้อความเพิ่มเข้าไปในคิวได้ หากคุณไปคัดลอกอย่างอื่นลงคลิปบอร์ดในระหว่างนี้ โหมดดังกล่าวจะสิ้นสุดลงและ Ctrl+V จะทำงานเป็นการวางตามปกติ


ล้างคลิปบอร์ด


กด Ctrl+Shift+V สามครั้งเพื่อล้างคลิปบอร์ดให้ว่างเปล่า NVDA จะพูดว่า "ล้างแล้ว" การทำเช่นนี้จะยุติโหมดวางทีละบรรทัดและล้างประวัติคำพูดที่บันทึกไว้สำหรับฟังก์ชัน "คัดลอกจนถึงคำพูดล่าสุด" ด้วย


คัดลอกข้อความในหน้าต่าง


กด Shift+Windows+V เพื่อคัดลอกข้อความทั้งหมดของหน้าต่างที่ใช้งานอยู่ไปยังคลิปบอร์ด หากหน้าต่างนั้นไม่มีข้อความโดยตรง simpleCopy จะอ่านข้อความของคอนטרولที่กำลังโฟกัสอยู่ผ่านเคอร์เซอร์ตรวจสอบแทน NVDA จะประกาศจำนวนตัวอักษรและบรรทัดที่คัดลอก จากนั้นจะเปิดหน้าต่าง "ข้อความที่คัดลอก" แบบอ่านอย่างเดียวขึ้นมาแสดงข้อความที่คัดลอกไว้อย่าง 100% กด Esc หรือเลือกปิดเพื่อกลับสู่การทำงานของคุณ


คัดลอก URL


ขณะอยู่ในเว็บเบราว์เซอร์ (Chrome, Firefox, Edge, Opera, Safari และ Brave) ให้กด Ctrl+Shift+A 1 ครั้งเพื่อคัดลอก URL ของหน้าปัจจุบัน NVDA จะพูดว่า "คัดลอก" ตามด้วย URL นั้น และ URL จะถูกเพิ่มลงในประวัติ URL หากไม่พบ URL ใด ๆ NVDA จะพูดว่า "ไม่พบ URL"


เมื่อคุณอยู่ในช่องแก้ไขข้อความ หรือในแอปพลิเคชันที่ไม่ใช่เบราว์เซอร์ ชุดคำสั่งนี้จะถูกส่งต่อไปยังแอปพลิเคชันนั้น ๆ โดยไม่มีการเปลี่ยนแปลง


คัดลอกไฮเปอร์ลิงก์


ย้ายวัตถุตัวนำทางไปยังลิงก์บนหน้าเว็บแล้วกด Ctrl+Shift+A สองครั้ง URL ของลิงก์นั้นจะถูกคัดลอก ประกาศให้ทราบ และเพิ่มลงในประวัติ URL หากไม่มีลิงก์ NVDA จะพูดว่า "ไม่พบลิงก์"


ประวัติ URL


กด Ctrl+Shift+A สามครั้งเพื่อเปิดหน้าต่างประวัติ URL หน้าต่างนี้จะแสดงรายการ URL ทั้งหมดที่คุณคัดลอกด้วยคำสั่งคัดลอก URL หรือคัดลอกไฮเปอร์ลิงก์ โดยเรียงจากรายการล่าสุดขึ้นก่อน และจำได้สูงสุด 300 URL ระหว่างเซสชัน URL ที่คุณคัดลอกซ้ำจะถูกย้ายขึ้นไปอยู่ด้านบนสุดของรายการ


  1. กด Ctrl+Shift+A สามครั้งเพื่อเปิดรายการ
  2. ใช้ปุ่มลูกศรขึ้นและลงเพื่อเลือก URL ที่ต้องการ
  3. กด Enter เพื่อคัดลอก URL ที่เลือกไปยังคลิปบอร์ด หน้าต่างจะปิดลงและ NVDA จะประกาศข้อความที่คัดลอก
  4. กด Delete เพื่อลบ URL ที่เลือก หรือกด Esc เพื่อปิดหน้าต่าง

เปิดเมนูบริบทบนรายการใดก็ได้ (กดปุ่ม Applications หรือคลิกขวา) เพื่อดูตัวเลือกเพิ่มเติม:


  • ล้าง: ลบรายการทั้งหมดที่ไม่ถูกปักหมุดไว้
  • ปักหมุด / เลิกปักหมุด: ป้องกันไม่ให้รายการถูกลบเมื่อล้างข้อมูลหรือถูกตัดทิ้งโดยอัตโนมัติเมื่อรายการเต็ม
  • ย้ายขึ้น / ย้ายลง: เปลี่ยนตำแหน่งของรายการในลำดับ
  • แก้ไข: กำหนดชื่อที่แสดงเสริมให้กับรายการแทนที่จะแสดงเป็น URL โดยสามารถเว้นว่างไว้เพื่อกลับมาแสดง URL ตามเดิมได้
  • ลบ: ลบรายการนั้นออก

คัดลอกคำพูดล่าสุด


กด F9 1 ครั้งเพื่อคัดลอกคำพูดล่าสุดที่ NVDA พูดไปยังคลิปบอร์ด มีเสียงบี๊บยืนยันการคัดลอก พร้อมทั้งเริ่มต้นการบันทึกคำพูดทั้งหมดที่ NVDA จะพูดต่อจากนี้เพื่อใช้สำหรับฟังก์ชัน "คัดลอกจนถึงคำพูดล่าสุด"


ต่อท้ายคำพูดล่าสุด


กด F9 สองครั้งเพื่อนำคำพูดล่าสุดของ NVDA ไปต่อท้ายในบรรทัดใหม่ของคลิปบอร์ด โดยไม่ลบข้อความเดิมที่มีอยู่ NVDA จะพูดว่า "ต่อท้าย"


คัดลอกจนถึงคำพูดล่าสุด


รวบรวมคำพูดต่อเนื่องยาว ๆ เช่น ข้อความแชทหลายบรรทัดหรือรายการยาว ๆ ที่คุณอ่านผ่านมา ให้มารวมอยู่ในคลิปบอร์ดรายการเดียว


  1. กด F9 หนึ่งครั้งที่รายการแรกที่คุณต้องการ ระบบจะคัดลอกและเริ่มบันทึกเสียง
  2. เลื่อนอ่านหรือฟังรายการอื่น ๆ ที่คุณต้องการต่อไป ทุกสิ่งที่ NVDA พูดจะถูกบันทึกไว้
  3. กด F9 สามครั้ง NVDA จะพูดว่า "คัดลอกจนถึงล่าสุด" และข้อความทั้งหมดที่บันทึกไว้นับตั้งแต่การคัดลอกครั้งแรกจะถูกนำมาวางลงในคลิปบอร์ด โดยมีรายการละหนึ่งบรรทัด

หากไม่มีการบันทึกข้อความใด ๆ คุณจะได้ยินเสียงบี๊บแจ้งข้อผิดพลาด ข้อความที่ตัว simpleCopy พูดเองจะไม่ถูกบันทึก


การนำทางประวัติคำพูด


simpleCopy จะบันทึกคำพูด 500 รายการล่าสุดที่ NVDA เคยพูดไว้ กด Shift+F9 1 ครั้งเพื่อฟังรายการก่อนหน้า ย้อนกลับไปเรื่อย ๆ ทุกครั้งที่กด กด Shift+F9 สองครั้งเพื่อเลื่อนไปข้างหน้ากลับสู่รายการล่าสุด หากไม่มีรายการถัดไปในทิศทางนั้นแล้ว คุณจะได้ยินเสียงบี๊บแจ้งข้อผิดพลาด


เปิดไฟล์ประวัติคำพูด


กด Shift+F9 สามครั้งเพื่อบันทึกประวัติคำพูดทั้งหมดลงในไฟล์ข้อความและเปิดขึ้นมาในโปรแกรมแก้ไขข้อความเริ่มต้นของคุณ รายการที่ซ้ำกันจะแสดงเพียงครั้งเดียวโดยให้รายการใหม่ที่สุดอยู่ด้านบนสุด ไฟล์นี้มีประโยชน์สำหรับการตรวจสอบหรือค้นหาทุกสิ่งที่มีการพูดคุยกันในระหว่างเซสชันของคุณ



สนับสนุนฉัน
