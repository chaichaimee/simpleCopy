simpleCopy


Copia, añade y gestiona texto eficientemente con NVDA


author: chai chaimee

url: https://github.com/chaichaimee/simpleCopy

Descripción


simpleCopy es un complemento ligero para NVDA que simplifica la copia de textos, la extracción de URLs, la gestión del historial de voz y la organización del historial de URLs.


Esta herramienta te ayuda a capturar y organizar información rápidamente sin interrumpir tu flujo de trabajo. Ya sea que estés copiando texto, capturando enlaces web, guardando contenido pronunciado o gestionando URLs de uso frecuente, simpleCopy ofrece atajos de teclado intuitivos que funcionan perfectamente con NVDA.


Atajos de teclado


Todos los comandos utilizan un sistema de pulsación múltiple. Presiona la combinación de teclas una, dos o tres veces en rápida sucesión para realizar diferentes acciones.


CTRL+Shift+A — URL, enlace e historial de URLs

Pulsación simple: Copia la URL de la página web actual.

Pulsación doble: Copia la URL de destino del hiperenlace enfocado.

Pulsación triple: Abre el cuadro de diálogo Historial de URLs para gestionar las URLs e hiperenlaces guardados.


CTRL+Shift+V — Copiar texto, añadir y gestión del portapapeles

Pulsación simple: Copia el texto seleccionado. Si ya existe texto en el portapapeles, la nueva selección se añade al final.

Pulsación doble: Copia el texto desde la posición actual del cursor de revisión. Esto funciona con cualquier selección realizada usando el cursor de revisión de NVDA, incluidas selecciones de múltiples líneas y de todo el documento.

Pulsación triple: Borra todo el contenido del portapapeles.


F9 — Captura y gestión de voz

Pulsación simple: Copia la salida de voz más reciente de NVDA.

Pulsación doble: Añade la salida de voz más reciente al contenido existente del portapapeles.

Pulsación triple: Copia toda la salida de voz acumulada desde la primera pulsación de F9.


Shift+F9 — Navegación por el historial de voz

Pulsación simple: Navega al elemento anterior del historial de voz.

Pulsación doble: Navega al siguiente elemento del historial de voz.

Pulsación triple: Abre el archivo de registro completo del historial de voz.


Características


Así es como funciona cada característica en la práctica:


1. Copia de URL de página web

Presiona CTRL+Shift+A una vez mientras navegas por cualquier sitio web. La URL de la página actual se copia en tu portapapeles. NVDA lo confirma anunciando la URL copiada.


2. Extracción de URL de hiperenlace

Enfócate en cualquier enlace y presiona CTRL+Shift+A dos veces. La URL de destino se extrae y se copia sin abrir el enlace.


3. Copia y adición de texto

Selecciona texto y presiona CTRL+Shift+V una vez. Si el portapapeles está vacío, se copia el texto. Si el portapapeles ya contiene texto, la nueva selección se añade con un salto de línea.


4. Copia del cursor de revisión

Utiliza el cursor de revisión de NVDA para seleccionar texto (usando NVDA+Shift+Flecha abajo o NVDA+Ctrl+Shift+Flecha abajo para seleccionar varias líneas), luego presiona CTRL+Shift+V dos veces. Todo el texto seleccionado desde la posición del cursor de revisión se copia al portapapeles. Esto funciona con cualquier tamaño de selección, desde una sola palabra hasta un documento entero.


5. Limpieza del portapapeles

Presiona CTRL+Shift+V tres veces para borrar instantáneamente todo el contenido del portapapeles. NVDA lo confirma con el mensaje "Clean".


6. Copia de la última voz

Cuando NVDA diga algo que quieras guardar, presiona F9 una vez. La última frase pronunciada se copia en tu portapapeles.


7. Adición de voz

Presiona F9 dos veces para añadir la última frase pronunciada al contenido existente del portapapeles.


8. Registro del historial de voz

Presiona F9 tres veces para copiar toda la salida de voz acumulada durante tu sesión actual.


9. Navegación por el historial de voz

Usa Shift+F9 una vez para retroceder en el historial de voz, y Shift+F9 dos veces para avanzar. Esto te permite revisar la salida de voz pasada sin cambiar tu foco actual.


10. Acceso al archivo de registro de voz

Presiona Shift+F9 tres veces para abrir el archivo completo del historial de voz en tu editor de texto predeterminado para revisarlo, buscar o copiar.


11. Gestión del historial de URLs

Presiona CTRL+Shift+A tres veces para abrir el cuadro de diálogo Historial de URLs. Este cuadro de diálogo almacena cada URL e hiperenlace que copies usando CTRL+Shift+A (pulsación simple o doble), para que puedas acceder a ellos más tarde.


Uso del cuadro de diálogo Historial de URLs:

- Presiona Enter en cualquier elemento para copiar esa URL al portapapeles. NVDA anunciará la URL copiada.

- Presiona la tecla Aplicaciones o haz clic derecho para abrir el menú contextual.

- Desde el menú contextual, puedes Anclar, Editar, Mover arriba, Mover abajo o Eliminar un elemento.

- Presiona la tecla Supr para eliminar rápidamente el elemento seleccionado.

- Usa Limpiar desde el menú contextual para eliminar todos los elementos que no estén anclados.


Anclaje y nombres de visualización:

- Los elementos anclados están protegidos contra la limpieza automática y el comando Limpiar.

- Puedes asignar un nombre de visualización personalizado a cualquier URL eligiendo Editar. Esto es especialmente útil para URLs que usas a menudo, facilitando su identificación en la lista.


Límite de almacenamiento:

- El historial de URLs está limitado a 300 elementos. Cuando se alcanza el límite, los elementos no anclados más antiguos se eliminan automáticamente para dejar espacio a los nuevos.


12. Conciencia de contexto inteligente

Cuando estás escribiendo en campos editables, simpleCopy no interfiere. Los comandos solo se activan cuando son útiles, preservando tu flujo de trabajo normal.
