simpleCopy


Copia, adjunta, pega y captura cualquier cosa que escuches, leas o navegues con unas pocas combinaciones de teclas sencillas.


autor: chai chaimee

url: https://github.com/chaichaimee/simpleCopy


Introducción


simpleCopy convierte el portapapeles en un espacio de trabajo rápido y accesible. Te permite recopilar varios fragmentos de texto en un solo portapapeles, pegarlos de vuelta línea por línea, copiar todo el texto de una ventana, capturar la dirección de la página web o enlace en el que te encuentras y copiar cualquier cosa que NVDA acaba de pronunciar. Un historial de URL incorporado mantiene las direcciones que has capturado para que puedas reutilizarlas más tarde.


Cada acción es anunciada por voz o mediante un pitido corto, por lo que siempre sabes si la operación se realizó correctamente.


Métodos abreviados de teclado


Ctrl+Shift+A
Pulsación simple: Copiar URL
Doble pulsación: Copiar hipervínculo
Triple pulsación: Historial de URL
Ctrl+Shift+V
Pulsación simple: Copiar y adjuntar texto
Doble pulsación: Pegar línea por línea
Triple pulsación: Limpiar portapapeles
Shift+Windows+V
Pulsación simple: Copiar texto de la ventana y mostrarlo
F9
Pulsación simple: Copiar último discurso
Doble pulsación: Adjuntar último discurso
Triple pulsación: Copiar hasta el último discurso
Shift+F9
Pulsación simple: Elemento anterior del historial de voz
Doble pulsación: Siguiente elemento del historial de voz
Triple pulsación: Abrir archivo del historial de voz

Características


Copiar y adjuntar texto


Selecciona un texto y presiona Ctrl+Shift+V una vez. La primera selección se copia al portapapeles. Cada selección posterior se añade al final del portapapeles en una nueva línea en lugar de reemplazarlo, y NVDA te indica cuántos caracteres se agregaron y el nuevo total. Esto te permite recopilar texto de varios lugares en un solo portapapeles.


Si no hay nada seleccionado, la combinación de teclas se pasa a la aplicación como un Ctrl+Shift+C normal.


Ejemplo:

  1. Selecciona el primer párrafo y presiona Ctrl+Shift+V. NVDA dice "Copiado".
  2. Selecciona un párrafo en otro documento y presiona Ctrl+Shift+V. NVDA dice "Adjuntado" junto con el número de caracteres y el total.
  3. Pega con Ctrl+V. Ambos párrafos aparecen, uno debajo del otro.

Pegar línea por línea


Toma el texto del portapapeles y lo pega línea por línea, para que puedas rellenar varios campos o formularios desde un solo bloque de texto. Las líneas vacías se omiten.


  1. Copia o adjunta el texto que deseas utilizar.
  2. Presiona Ctrl+Shift+V dos veces. Escucharás un pitido y NVDA anunciará el número de líneas.
  3. Mévete al primer lugar donde quieras el texto y presiona el Ctrl+V normal. Se pega la primera línea y NVDA anuncia el número de línea.
  4. Mévete al siguiente lugar y presiona Ctrl+V de nuevo. Se pega la siguiente línea.
  5. Repite hasta que se pegue la última línea. Un pitido agudo te indica que la lista ha terminado, y el texto original de tu portapapeles se restaurará automáticamente.

Mientras el modo línea por línea esté activo, aún puedes presionar Ctrl+Shift+V una vez para adjuntar más texto a la cola. Si copias otra cosa al portapapeles mientras tanto, el modo finaliza y Ctrl+V pega normalmente.


Limpiar portapapeles


Presiona Ctrl+Shift+V tres veces para vaciar el portapapeles. NVDA dice "Limpiado". Esto también finaliza el modo línea por línea y borra cualquier discurso capturado para "Copiar hasta el último discurso".


Copiar texto de la ventana


Presiona Shift+Windows+V para copiar todo el texto de la ventana activa al portapapeles. Si la ventana no proporciona texto directamente, simpleCopy lee el texto del control enfocado a través del cursor de revisión. NVDA anuncia el número de caracteres y líneas que se copiaron, y luego abre una ventana de solo lectura titulada "Texto copiado" que muestra exactamente lo que se copió. Presiona Escape o selecciona Cerrar para volver a tu trabajo.


Copiar URL


En un navegador web (Chrome, Firefox, Edge, Opera, Safari y Brave), presiona Ctrl+Shift+A una vez para copiar la dirección de la página actual. NVDA dice "Copiar" seguido de la dirección, y la dirección se añade al historial de URL. Si no se puede encontrar ninguna dirección, NVDA dice "Sin URL".


Cuando te encuentres en un campo de edición, o en una aplicación que no sea un navegador, la combinación de teclas se pasa a la aplicación sin cambios.


Copiar hipervínculo


Mueve el objeto navegador a un enlace en una página web y presiona Ctrl+Shift+A dos veces. La dirección de ese enlace se copia, se anuncia y se añade al historial de URL. Si no hay ningún enlace, NVDA dice "Ningún enlace encontrado".


Historial de URL


Presiona Ctrl+Shift+A tres veces para abrir la ventana del historial de URL. Enumera todas las direcciones que copiaste con Copiar URL o Copiar hipervínculo, comenzando por la más reciente, y recuerda hasta 300 direcciones entre sesiones. Una dirección que vuelvas a copiar se mueve a la parte superior de la lista.


  1. Presiona Ctrl+Shift+A tres veces para abrir la lista.
  2. Usa las flechas arriba y abajo para elegir una dirección.
  3. Presiona Enter para copiar la dirección seleccionada al portapapeles. La ventana se cierra y NVDA anuncia lo que se copió.
  4. Presiona Supr para eliminar la dirección seleccionada, o Escape para cerrar la ventana.

Abre el menú contextual en un elemento (tecla Aplicaciones o clic derecho) para ver más opciones:


  • Limpiar: elimina todos los elementos que no están fijados.
  • Fijar / Desfijar: protege un elemento de Limpiar y del recorte automático cuando la lista está llena.
  • Subir / Bajar: cambia la posición del elemento en la lista.
  • Editar: asigna al elemento un nombre de visualización opcional que se muestra en lugar de la dirección. Deja el nombre vacío para volver a mostrar la dirección.
  • Eliminar: elimina el elemento.

Copiar último discurso


Presiona F9 una vez para copiar al portapapeles lo último que dijo NVDA. Un pitido confirma la copia. Esto también inicia la grabación de todo lo que NVDA diga a partir de entonces, lo cual es utilizado por "Copiar hasta el último discurso".


Adjuntar último discurso


Presiona F9 dos veces para añadir lo último que dijo NVDA al final del portapapeles, en una nueva línea, sin reemplazar lo que ya está allí. NVDA dice "Adjuntar".


Copiar hasta el último discurso


Recopila un tramo completo de voz, por ejemplo, varias líneas de un chat o una lista larga que leas, en una sola entrada del portapapeles.


  1. Presiona F9 una vez en el primer elemento que desees. Se copia y comienza la grabación.
  2. Continúa y escucha los demás elementos que desees. Todo lo que dice NVDA queda grabado.
  3. Presiona F9 tres veces. NVDA dice "Copiar hasta el último", y todo lo grabado desde la primera copia se coloca en el portapapeles, un elemento por línea.

Si no se ha grabado nada, escucharás un pitido de error. Los mensajes pronunciados por el propio simpleCopy no se graban.


Navegación del historial de voz


simpleCopy guarda las últimas 500 cosas que NVDA ha pronunciado. Presiona Shift+F9 una vez para escuchar el elemento anterior, retrocediendo más cada vez. Presiona Shift+F9 dos veces para avanzar nuevamente hacia el elemento más reciente. Cuando no hay nada más en esa dirección, escucharás un pitido de error.


Abrir archivo del historial de voz


Presiona Shift+F9 tres veces para guardar el historial de voz en un archivo de texto y abrirlo en tu editor de texto predeterminado. Las líneas duplicadas se enumeran solo una vez, con la más reciente primero. El archivo es útil para revisar o buscar todo lo que se habló durante tu sesión.
